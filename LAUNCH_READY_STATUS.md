## 🛠️ Technology Stack

### Frontend
- **Framework**: React 18+ with TypeScript
- **Styling**: Tailwind CSS
- **Charts**: Recharts (5 chart types)
- **Components**: shadcn/ui (Card, Button, Badge, Progress, Tabs)
- **Icons**: Lucide React
- **State**: React Query + Context
- **Real-time**: Socket.IO client

### Backend (Required for Full Functionality)
- **Framework**: Express.js
- **Database**: PostgreSQL + Prisma ORM
- **Real-time**: Socket.IO server
- **Auth**: Session-based + JWT
- **APIs**: RESTful + GraphQL ready

### Deployment
- **Frontend**: Vercel (with custom domain support)
- **Backend**: Railway (production-grade)
- **Database**: PostgreSQL (Railway/custom)
- **CDN**: Vercel Edge Network
